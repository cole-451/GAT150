# Box Wars...The Shipping Fee Due (GAT150 Project)

## Description
Play as a crate-hating ghost whose main goal is to try and throw as many boxes as they can off of the stage.
Take too long without knocking any crates off, and your game is over.
This uses the Parabellum Engine, a custom-made game engine that supports physics, audio, sprites, and much more.

## Features
- Instance-based object creation via .json parsing.
- Modular object creation through adding components.
- Animated sprite system
- Dynamic 2D physics for objects

## Controls
Press "k" to start the game.
WASD to move.
Space to jump.
Press "r" to restart the game.
